## Рекомендации

1. **Шифрование**: рассмотреть пул буферов (`sync.Pool`) для снижения аллокаций в AEAD
2. **WebSocket**: при >50K подключений рассмотреть epoll/kqueue (gobwas/ws)
3. **Kafka**: увеличить количество партиций для линейного масштабирования throughput
4. **GC**: при высоком heap рассмотреть GOGC tuning или ballast
5. **Протокол**: batching мелких сообщений для снижения overhead
